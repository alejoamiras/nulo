# legal/archive/

One frozen copy per superseded version, named `<doc>-<version>.md` (`terms-1.0.md`). The landing
publishes each at its permalink (`nulo.sh/terms/v1.0/`), which is what an installed wallet links to,
so a user can always read the text they actually accepted.

Copy the current document here **before** editing it for a new version. `@nulo/legal`'s tests fail
when a superseded manifest version has no file in this directory. Never edit an archived file.
