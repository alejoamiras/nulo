## Security & Adversarial Considerations
Threat model: attacker-controlled backup blob, attacker-recomputable plain checksum (not auth). Assets: other profiles' data (A/B/C/D) + verifiable privacy-erasure on delete (D). Closes every cross-profile WRITE primitive + makes "deleted" mean "verifiably erased or pending-retryable." New tombstone state is hostile-adjacent on read-back (fail-closed on id-reuse, D11). Do NOT weaken CI gates. Every-phase audit ask: "what still reaches a victim? can deletion leave/resurrect/false-succeed? can the coordinator deadlock/partial-commit? attack the Assumptions."
