# C2 lessons — the policy library and the fonts

## Font provenance, checked before any text was vendored

Read from each binary's `name` table (fontTools) and from upstream's licence file:

| File | Family, version | Copyright | Licence | Reserved Font Name |
|---|---|---|---|---|
| `InterVariable.woff2` (2,937 glyphs, the full variable font) | Inter Variable 4.001 | 2016 The Inter Project Authors | OFL-1.1 | none declared |
| `SpaceGrotesk-latin.woff2`, `-latin-ext.woff2` (291 / 429 glyphs, subsets) | Space Grotesk 2.000 | 2020 The Space Grotesk Project Authors | OFL-1.1 | none declared |
| `JetBrainsMono-latin.woff2` (394 glyphs, subset) | JetBrains Mono 2.211 | 2020 The JetBrains Mono Project Authors | OFL-1.1 | none declared |
| `MaterialSymbolsOutlined.woff2` (3,972 glyphs) | Material Symbols Outlined 2.930 | Google LLC | Apache-2.0 | n/a; upstream ships no `NOTICE` (404) |

**The stop condition did not fire.** Subsetting is modification under the OFL, and a modified
version may not use a Reserved Font Name. All three OFL licence files mention the term only in the
definitions clause; none reserves a name, so the subsets may keep theirs. How the subsets were made
is not recorded anywhere in the repo (they arrived with the design-system externalisation), which
is why the claims bind by SHA-256 rather than by file name: whatever they are, these exact bytes
are what was reviewed.

Texts are upstream's files, verbatim: Inter at tag `v4.1`, JetBrains Mono at `v2.304`, Space
Grotesk at commit `4a44bc96` and Material Symbols at `68e015db` (the last commits to touch each
licence file; the vendored bytes were re-hashed against those commits).

## What bit

- **Two functions went one point over the complexity budget** (`bundleContents`, `vendoredEntries`)
  from a three-line font addition each. Both were already at 15. Extracted `recordAsset` and
  `accountingProblems`; no suppression.
- **Licence texts live in this package's `texts/`, not beside the fonts.** The plan put them in
  `@nulo/design`; that needs a second texts directory in the generator for no compliance gain (the
  OFL asks that the text travel with the font, and one copy in the repository and one in the
  shipped notices file is that). The landing and tools apps adopting the library is a follow-up.

## Codex loop

**Round 1 (GPT-6 Astra, `high`): reject, two findings, both accepted.**
- An emitted `.ttf`, `.otf`, `.eot` or upper-case `.WOFF2` needed no claim: only `.woff2?` was a
  font. One `FONT_ASSET` pattern, case-insensitive, now drives the claim rule, the hashing and the
  real-file test. No further format is *allowed*; they are only recognised, so they refuse.
- An emptied reviewed text shipped an entry with no licence in it. `readTexts` now refuses a blank
  file by name, on the path overrides and vendored components share.
Non-blocking, applied: the two licence URLs on a mutable branch are pinned to commits.

**Round 2: approve.** No blocking finding; Codex's own probes confirmed both fixes and that the five
fonts still produce byte-stable output. Its two notes are applied: `codeAsset` is derived from
`FONT_ASSET` so the two cannot drift, and the format regression now asserts the refusal itself.
The loop closed in two rounds of three.
