# Phase 2 lessons — chain identity + shared formula

- **The l1ChainId-on-Account-row design (fable H1-alt) held up in implementation**: the coordinator's default deriver became a two-line call through the shared `deriveAccountSeed` reading the row — no service dependency, works pre-session-open. `AccountService.init` already held a NetworkService reference, so no injected delegate was needed at all — `resolveVerifiedL1ChainId`/`getL1ChainIdStored` live on NetworkService (which owns the probe + the seeded-constant map).
- **Auth-first mattered twice**: `createAccountInternal` fetches the master (auth gate) BEFORE `resolveVerifiedL1ChainId` — both because unauthorized callers must not trigger custom-network probes, and because `serialize-per-tuple.test.ts` pins the "unauthorized" rejection as the FIRST failure.
- **Real-deriver pin without poseidon**: jsdom can't run bb.js, so `coordinator.default-deriver.test.ts` mocks the two module boundaries (`deriveAccountSeed`, `NuloAccount.new`) and asserts the production default ROUTES through the shared function with the row-carried l1ChainId. The formula's values are pinned separately by aztec-runtime's node-env KATs — together they close audit H1's "unit gate can't see a stale default" gap.
- **Probe fakes report l1ChainId 0** (`nodeInfoForChain` → `{l1ChainId: 0, rollupVersion: chainId}`) — network-test literals therefore carry `l1ChainId: 0` so the new exact-L1 endpoint-mutation checks pass alongside the composite assertions they exercise.
- **Deviation from P2's letter, faithful to intent**: the canary's recompute line moved to v2 (separator-prepend + l1=31337 inline, deliberately hand-rolled), but `import-drivers.ts`'s `deriveNuloAccountAddress` + its synthetic-backup fixtures move together in P4 — updating the formula while the fixtures still lack `l1ChainId`/epoch-4 would create an incoherent intermediate that nothing runs anyway (those tests only execute in the P4 smoke / P6 network gates).
- Typecheck fallout was exactly 11 errors in 3 test files, zero production surprises — the recon map's "no UI constructs these rows" held.
