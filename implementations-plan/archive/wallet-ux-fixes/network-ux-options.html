Four ways to fix the network list

The list looks selectable but isn't — pick the direction, and I'll build it.

Today each row shows a left circle / filled-circle that reads like a radio button, but tapping a row only opens its detail page — switching the active network happens one screen deeper. So people tap the circle expecting a switch, nothing happens, and it feels broken. The four options below each resolve that mismatch differently. Mockups are the real dark popup at ~1× scale.

Which one?

My pick: B (Active badge). It's the smallest, safest change — it fixes the actual complaint (the fake-radio) by making the affordance honest, with no interaction rework and no new mis-tap surface. Both plan auditors independently favoured it for the same reason.

If your real goal is faster switching (not just "stop it looking broken"), C matches the instinct people already have, at the cost of a bigger rework. D is the most explicit but spends the most layout. A is the middle path but crowds two targets into one small row.
