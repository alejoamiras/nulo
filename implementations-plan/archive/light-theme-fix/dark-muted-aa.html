Dark muted-text → WCAG-AA (follow-up #1)

The light-theme fix raised the light muted-grey tokens to the AA readability bar (4.5:1) after codex caught that they carry security copy — the scam-token "Allow?" warning, the "irreversible" confirm, reset guidance. The dark theme had the same tokens at the same low opacity, so the same copy was also sub-AA in dark. This page shows the before/after. Everything below is rendered with the real token values and the contrast ratios are computed live (WCAG 2.x) — not eyeballed.

AA for normal text = 4.5:1. The fix targets the lightest dark surface (surface-high, the lowest-contrast case) so every surface clears the bar.
