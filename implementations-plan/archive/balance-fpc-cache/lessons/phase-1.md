- **Enum vacuity trap**: the first draft of the optimistic-deduction pin passed a string `"PREEXISTING_FEE_JUICE"` where the card compares a NUMERIC enum (`AccountFeePaymentMethodOptions.PREEXISTING_FEE_JUICE = 1`) — the pin would have passed vacuously forever. Caught by checking the enum source before running. Rule of thumb: reach-in event pins must use the same imported constants the component compares against.
