## Implementation
- New `packages/extension/src/wallet/services/execution/mark-failed-unless-cancelled.ts`:
  `markFailedUnlessCancelled(error, journalId, lane): Promise<unknown>` → if NOT `JobCancelledSentinel`,
  `lane.markJournal(journalId, {stage:"failed"}, normalizeError(error, "dapp_execute"))`; always RETURNS the
  error so the caller `throw`s it (the throw stays at the call site → catch/finally shape + ordering unchanged).
- The 3 dapp-send catch arms (`executeSendTransaction`:246 / `executeAztecSendTx`:409 / `executeNoFromSendTx`:598
  — byte-identical) → `} catch (error) { throw await markFailedUnlessCancelled(error, journalId, this.deps.lane) }`.
  `normalizeError` dropped from the dapp-send-executor import (now only used in the helper).
- **transfer-executor EXCLUDED (assessed):** its catch differs — `maybeRethrowAsRpcCancel(error, transferTask)` +
  a local `markJournal` closure over `transitionJournal` + `"transfer"` context + `transferTask.fail(error)`.
  Folding it would force a generic helper AND obscure the transfer-specific cancel mapping. Stays inline.
- Behavior-identical (cancelled → rethrow, no mark; else → mark failed + rethrow). Net change small.
- Tests: `mark-failed-unless-cancelled.test.ts` (4) — sync-throw on sentinel (no markJournal); generic→markJournal
  failed (normalized dapp_execute); markJournal-promise passthrough (proves no async wrapper); undefined journalId.

## codex post-impl fix loop (the discipline paid off)
codex `019ef365` returned **FIX-FIRST**: the first cut made the helper `async` and used `throw await
markFailedUnlessCancelled(...)`, which inserted a microtask before the `throw` on BOTH paths — delaying each
pipeline's `finally` (controller cleanup + slot release) by one microtask vs the original synchronous
`if (sentinel) throw; await markJournal; throw`. A real ordering change on the cancel/slot path that the e2e
would NOT reliably catch. **Fix:** helper is now SYNCHRONOUS (throws the sentinel synchronously during the
caller's `await` evaluation; returns `markJournal`'s own promise), call site is `await
markFailedUnlessCancelled(...); throw error` — microtask-identical to the original for both paths. codex resume
**SHIP — no remaining timing/propagation delta**. Pin added: `expect(returned).toBe(marker)` (promise
passthrough) + `expect(() => fn(sentinel,…)).toThrow()` (synchronous throw, not a rejected promise).
