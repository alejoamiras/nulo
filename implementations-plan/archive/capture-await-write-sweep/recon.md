## §3 Shared-state substrate (enumeration grep seeds)

Read APIs whose results become stale snapshots across awaits (per surface; writers + mid-await mutators in parentheses):

1. **EntityStorage/ValueStorage** (`packages/wallet-core/src/storage/entity_storage.ts`, `value-storage.ts`): reads `get/contains/getAll/getKeys/getValues/rawEntries/rawStringEntries/rawValue`; writes `set(id,entity)/delete(id)`, `ValueStorage.set/delete`. NO read-modify-write atomicity; any concurrent set/delete interleaves. Read path deliberately never deletes malformed rows (B-23). UI-side facade `apps/extension/src/utils/storage.ts` gates on `migrationIdle()`.

Mutators: deleteProfile cascade (reserve+bump sync first), passkey ceremonies (minutes), SW restart (pending maps die; boot resume sweeps), AccountIntegrityCoordinator block.

7. **In-memory caches**: `memoizeAsync(By)` (`aztec-runtime/src/pxe/async-memo.ts`, rejection-clearing identity-guarded); `SingleShotTtlCache` (`execution/estimate-reuse-shared.ts`, pop-on-read + `pendingHashesChanged`); `PriceService` (`price/service.ts`: persisted ValueStorage + in-memory `generation` re-checked after EVERY await, `inflight`, abortController); NetworkService node maps; wallet-sdk closure maps; `PasskeyService.pending`; `DappInteractionService` in-memory Map; `TaskService.tasks`.
