The lock button looks like the privacy lock

Popup header
Your noteThe icon for locking the wallet is the same as for PUBLIC / PRIVATE references. And it's also not very clear it's going to lock the wallet, maybe a tooltip on hover?

What the code does

  • The header's lock is a bare 20px padlock (Header.vue) with only an aria-label. One click locks at once, unless a send is still going out, in which case it asks "Lock anyway".
  • Right below it, the same padlock means private: the balance split and every token row pair lock (private) with globe (public), on purpose, with no words (BalanceView.vue).
  • The padlock also marks Security & Backup, the brand mark and password fields.

What others do

  • None of the nine wallets and password managers surveyed ships a bare, unlabeled lock button: MetaMask's menu says "Lock", Phantom's settings say "Lock Wallet", 1Password's toolbar says "Lock 1Password".
  • Bitwarden users ask for a visible "Lock now" (forum). The alternatives each mean something else: power means quit, a key means credentials, logout means signing out.
  • A tooltip only helps people who already hover over it, and never on a first glance (NN/g).

What changes

  • The icon button becomes a small bordered chip, "Lock", matching the network chip beside it. Same testid, same aria-label.
  • The privacy glyphs don't change. They were your deliberate call, and the label is enough to separate the two.

Clicks

Unchanged: one click locks; if a send is in flight, you're asked first.

Effort: small. The chip is about 30px wider than the icon; long network names already truncate.

What changes

  • "Lock wallet" appears after a short hover, or on keyboard focus. Nothing else changes.
  • It explains the button only to people who already suspect it's a button. On first look it still reads like the privacy lock.

Effort: trivial, once the tooltip fix from item 2 lands.

My pick: A

The confusion comes from the glyph standing alone, and a label fixes that for everyone at first sight; a tooltip fixes it only after someone investigates. Changing the glyph instead would cost more: every alternative means something else, and the lock/globe privacy pair is doing its job.

Confidence: high.
