**Status:** ✓ DONE. Squashed to `dev-quality` @ `7acbcfb` (PR #193). Gate: full network `28469251968` + smoke (1 known-flake re-run) + quality; aztec-runtime 38 + extension 109.

## What shipped (3 sub-refactors in aztec-runtime/pxe)
1. **`provingMode` discriminated union** for `ProductionPxeFactoryOptions` (`default`|`required`|`proverless` + orthogonal `AcceleratorEndpoint`) — the previously-illegal `required`+`proverless` combo is now unrepresentable (was a runtime throw).
2. **`ChainCoordinates` codec** (`chain-coordinates.ts`) owning `registryKey`/`dataDir` + their profile prefixes + `PXE_DATA_DIR_ROOT` — replaces ~7 inline `(profileId,chainId)` encodings.
3. **`NetworkInfo` → `ArtifactNetworkContext`** rename in artifact-registry (the dead `_network` param).

## Key lessons
- **Persisted strings are load-bearing.** The `pxe/${profileId}/${chainId}` form is the on-disk PXE IndexedDB name; the codec MUST be byte-identical (incl. the `p:`, `pxe/p/`, bare `pxe/` PREFIXES, not just full keys) or it orphans a user's PXE data. A `chain-coordinates.test.ts` pins the exact strings + prefix-match (this is a PURE module → unit-testable in aztec-runtime, unlike the artifact loaders).
- **DON'T touch the lookalike key:** `account/service.ts`'s `${profileId}:${chainId}:${type}` is a DIFFERENT 3-part key — out of scope (codex caught it).
- **DU illegal-combo = compile-time, not runtime.** Removed the runtime mutual-exclusion throw; pinned the rejection with a `@ts-expect-error` test (`{provingMode:"proverless", required:true}` → excess-property error). The constructor is no longer defensive for old-shape/`any`/JS callers — **accepted as an API break** per no-backwards-compat (all callers migrated + TS-typed; no JS/non-literal callers).
- **A DU rename makes doc-comments stale** — codex post-impl caught `offscreen/entry.ts` + the test header still documenting `{required,...}`; fixed.
- **Deferred (out of cited scope):** `storage/migrate.ts ["pxe/"]` is byte-identical + in the storage layer; centralizing would widen the codec export across a layer for marginal gain.
