**Status:** ✓ DONE. Squashed to `dev-quality` @ `032315c` (PR #195). Gate: full network `28471568437` + smoke `28471566725` + quality `28471564899` green. codex pre+post-impl ✓.

## What shipped
- `apps/extension/src/utils/files.ts:72` — `(chrome.runtime as any).lastError as {message?:string}|undefined` → `(chrome.runtime as unknown as { lastError?: { message?: string } }).lastError`. Dropped the `biome-ignore noExplicitAny`; kept the `"Download failed"` fallback string verbatim.
- `apps/extension/src/utils/general.js` → `general.ts`, fully typed: `isPrefersDarkScheme(): boolean` (`?? false`), `persistThemeHint(value: string): void`, `debounce = <T extends (...args: never[]) => unknown>(fn, delay): ((...args: Parameters<T>) => void)` with `let timeout: ReturnType<typeof setTimeout> | undefined`, `ensurePermissions(perms: chrome.permissions.Permissions): Promise<boolean>`. Deleted `general.d.ts`. `auto-imports.d.ts` regenerated by the build to `'../utils/general'`. `public/theme-boot.js` comment ref `general.js`→`general.ts`.

## Key lessons
- **codex SHRANK the finding (pre-impl).** The original scope ("centralize `lastError` reading on the port / extract one reader") was rejected as over-engineering: there's effectively ONE meaningful `chrome.runtime.lastError` site worth typing (`files.ts` download callback), and the `general.js` cleanup is an independent JS→TS migration. Centralizing on the messaging port would have coupled a leaf util to the transport layer for no real dedup. **Lesson: a "centralize X" finding can collapse to "type the one real site + migrate the stray JS file" — re-verify the dedup count before building the abstraction.**
- **JS→TS migration is mechanical but the auto-imports regen is load-bearing.** `general.js` was consumed via `unplugin-auto-import`; after rename, `auto-imports.d.ts` must be regenerated (the build does it) so the import path flips `'../utils/general'` cleanly. A stale `.d.ts` (`general.d.ts`) had to be DELETED — leaving it would shadow the new inferred types.
- **`as unknown as {…}` over `as any`** is the project-idiomatic fix for chrome-types `lastError` shim drift — it satisfies `noExplicitAny` (error-level) without a `biome-ignore`, and narrows to exactly `{ message?: string }`.
- **No behavior change** — pure typing + file-extension migration; the download error path, theme boot, debounce, and permission prompt all behave identically.

## Process
codex pre-impl simplified scope (drop port-centralization); post-impl audit = approve, no code changes. Behavior-preserving, validated by the full gate (the byte-identical built output means network e2e is a same-runtime confirmation).
