## Implementation
**Gap (a):** `useFormState` gains a mutable per-field `baseline` (init = `def.initial` → create dialogs unchanged, backward-compatible), `field.isDirty` (value !== baseline), and `rebase(values)` (sets value + baseline + clears touched; pass the full loaded set in one call for sibling-dependent validators). `isDirty`/`reset()` now use baseline. Adopted in EditEndpointPopup (`fillFromEndpoint`→rebase, `isDirty`→`form.isDirty`) + EditNetworkPopup (`handleFillFieldsWithDefaultValues`→rebase, `isStartedEditingName`→`form.fields.name.isDirty` — the per-field API codex specifically wanted for warning-gating, NOT `form.isDirty`). 5 new tests (dirty/reset/cross-field/partial after rebase).

**Gap (b) drifts (verified real, not intentional):** `SelectTokenPopup` had no `onTokenUpdated` handler though `TokenServiceClient` emits it (client.ts:12) → stale on rename; added it. `BalanceView.onBalanceDeleted` never removed the row (unlike add/push + update/splice) → stale after delete; added the filter, preserving the display-option side-effect.
