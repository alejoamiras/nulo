## Shared rationales

- **R-LOCK (SAFE-under-lock)**: read→write and all mutators share ONE lock acquisition. Watchdog caveat: a >5-min hold forfeits exclusivity; cited only where the CS can realistically park (PXE/network awaits) — those get explicit verdicts.
- **R-EPOCH (SAFE-fenced)**: generation/epoch captured before the first await it guards and re-checked with no await between check and write; capture order verified.
- **R-RESTORE (SAFE-fenced)**: N-14 entry-captured `captureRestoreEpochs` + `assertRestoreEpoch` flush against each write (batch-7 verified sites).
- **R-BOOT (SAFE-no-mutator)**: runs pre-RPC in `doStart` (single-flight memo; RPC handlers live only after start) — no concurrent service caller exists. Trail: `single-flight-start.ts`, runtime registration zone, N-28 gating.
- **R-SOLE (SAFE-no-mutator)**: the only caller path is structurally serial (named in the row). Mutator classes checked: other realms (popup writes via facade only to `nulo:ui:*`), events, ports, offscreen, restart recovery.
- **R-DERIVED (SAFE-lww, self-healing)**: write is a derived cache/projection rebuilt by the next event/tick; harm ceiling = transient staleness of derived data, no durable identity corruption. OWNER-ACK-PENDING applies where noted.
- **R-FLOW (SAFE-fenced, system-level — SENDING op kinds ONLY)**: the dApp SEND flow is closed by layered fences — dispatch-time binding guard + queued-record in-flight-send switch block (`SENDING_KINDS = {transfer, dapp_execute}` — verified) + deletion epoch at journal create/claim + D13 fence at `addTransaction` + session-manager fail-closed account resolution + switch-epoch delivery gate. Verified: `executeAndResolve` throws on profile mismatch (service.ts:174-179). **NON-send op kinds (register_token/register_contract/register_sender/authwit) are NOT switch-blocked** — each needs its own consumption-time assert: register_contract/sender fail closed via `getNetwork`'s active-profile `requireOwnedRow`; register_token did NOT (→ F11); createAuthWit signs under the session-validated account (delivery epoch-gated).
- **R-HANDOFF (watchdog-park class)**: harm requires a 5-min lock watchdog force-release mid-CS — the N-17 class. The note arm shipped post-park re-checks; the public arm (newer code) did not. Fixed for consistency where the file's own discipline demands it (F2), noted elsewhere.
- **R-IDEMP (SAFE-idempotent)**: racing writers converge on the same result (deterministic derivation / idempotent PXE registration / idempotent delete).
