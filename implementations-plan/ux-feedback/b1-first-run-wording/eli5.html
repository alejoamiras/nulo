The first PR of the stack. A new user sets up Nulo without ever being asked to name a "profile"; the fee card says plainly what you pay; the lock button says "Lock"; the send strip uses the same padlock and globe as the home screen; new accounts start at "Account 1".

Who it's for, and what excellent looks like

Someone opening Nulo for the first time who has never heard the word "profile", and anyone reading the fee on a small popup or a dApp window.

  • Setting up asks only how you'll unlock Nulo, on every page that can create your first profile.
  • The fee always fits on one line and says what you pay, including to screen readers.
  • It looks like the drawings, checked side by side.

Why the tests change so much

Every automated browser test starts by creating a profile through the page that loses its name field. So the test helpers change first: a test creating a first profile now checks that no name field appears and that the profile is "Main"; a test adding a later one checks the field shows "Profile 2". These checks are stricter than today's, not looser.

Why "light"

Wording and small layout changes in one app, nothing stored differently, no new permissions, no outside service. Risk scores: novelty low, blast radius medium (every test fixture), irreversibility low, migration none, outside dependencies none, security low. One cross-check by Codex is enough; the program caps every batch at "mid".

What the review caught

Codex read the plan against the code four times and approved it on the fourth (confidence high). What it found changed the plan:

  • Two existing bugs this work would have hidden. Restoring a full backup whose profile name is only spaces around an invisible character stored the raw, unsanitized name; and if reading the profile list failed, the Create button stayed stuck on "creating". Both are fixed and tested here, because hiding the name field would have made the first one invisible.
  • "no balance" when Nulo simply couldn't read it. Now "couldn't check balance", like the public option (U14).
  • A fee contract added by hand can charge you. It can't make you pay the network fee, but a contract written to act only when your account calls it could collect tokens you had already allowed it to take. So "free" is limited to Nulo's own sponsor (U16).
  • A missed test setup path and three more browser tests for the fee flows, now part of the gate.
