# Lessons — R4 (P18b PXE descriptor table) · deep, seam

Merged `c7da9f0` (#241), full gate green first-pass. The PXE half of Q-03, deferred from round-1.

## Scope discovery: half the phase already existed
Reading before designing found `subset.ts` — a round-1-era compile-time pin (`PXE_SUBSET_METHODS` +
`Expect/Equal` asserts) already synchronizing `Methods`/`IPXE`/`PXEProxy`, whose own header argued
full mapped-type derivation was "a larger step" (strip-network + promisify + ungeneratable zod). So
R4's real scope wasn't "add pins" but "make the pins DERIVED": the descriptor table becomes the
single source, the subset list is computed from `ipxe: true`, and the asserts move with it.
Lesson: on a "generate X from a table" phase, first find what the table must REPLACE — the shape of
the existing artifact tells you which derivations are worth it and which stay hand-written.

## What generated vs what stayed hand-written (the trust split)
- **Generated**: `PXEProxy`'s 18 forwards — byte-identical network curries, exactly the P18a
  `definePassthroughs` shape (declaration-merge for types + prototype installer + `.name`
  restoration + justified `noUnsafeDeclarationMerging` suppressions). The TS-private-field access
  works because the installer types `this` STRUCTURALLY (privacy is compile-time-only).
- **Hand-written, deliberately**: `service.ts`'s `defineRpcMethods` allowlist (THE dispatch trust
  boundary — Q-03's standing rule: never derive it from any table); `client.ts` (per-method zod
  response validation + the `proveTx` 30-min timeout — `git diff` untouched); `ipxe.ts` (the
  readable public seam consumers import — pinned by the table instead of derived from it).

## The flag invariants do real work
`ipxe ⇒ requiresNetwork` (a per-network facade can only carry network-curried methods) means
flipping `clearChainState` to `ipxe: true` fails the BUILD twice over — once on that invariant
(it's `requiresNetwork: false`) and once on `keyof IPXE ⇔ ipxe-true` (the interface wouldn't
match). The SW-only exclusion (`getNoteSchemas`/`getBlockTimestamp`/`clearChainState` — chain-purge
must never be reachable through a dApp-adjacent per-network handle) is now un-bypassable by a
single-file edit. `rpc` is all-true today and asserted so — it exists to force a deliberate
decision when a type-only/non-dispatched method first appears.
