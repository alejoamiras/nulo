The real privacy bug (why this matters)

When you export/back up one profile, the file also contains your other profiles' token balances. The export code looks up the active profile but then hands back every profile's balances (a dead variable — a classic bug). Your tokens and contacts export correctly; only balances leak. We fix it by returning only the active profile's balances. It changes what's in the file (drops the foreign data), not the file's format — so it's compatible with "don't touch backups." Two smaller, website-unreachable "guess-the-ID" gaps (internal code could reach another profile's token / another account's authwits by guessing a number) get seatbelts too.
