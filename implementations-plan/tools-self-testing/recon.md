## Gas-leg surface (facts)

- `useRouteQuote.ts` returns `unavailable/config` for EVERY token when `manifest.bridge.l1.swap` is undefined, before `discoverFuelRoute` runs; `ChoiceCards.vue` greys `token+gas` and `gas` on `no-route` and `unavailable` alike. So the sandbox's `swap: undefined` makes every gas cell unreachable in the UI.
- Discovery = `Multicall3.aggregate3(allowFailure:true)` batching `Quoter.quoteExactInputSingle` per hop depth, via `readContract` (`eth_call`); a revert is "no such pool"; `amountOut <= 0` is soft no-route. Candidates: `token===weth` → one hop on `ethFj`; else one two-hop route per `tiers[i]` (token↔WETH, native↔feeJuice at `ethFj`). Hooks must be `address(0)`.
- Router calls `swapTarget.swap(inputToken, amount, minOutput, path, zeroForOnes)`; `MockSwapTarget` ignores `path` and pays `amount*rateNum/rateDen` (`MOCK_RATE_NUM = 1e12`). The facade's chained hop math must compose to that multiplier or `minFuelOutput` mismatches at settlement.
- `useGasHeld.ts` reads public FJ only when `walletSupports(wallet, "dapp-self-pay")` (Nulo-custom `getWalletFeatures`, fail-closed); private FJ via PrivateFPC `balance_of`. `decideOwnGasSource` yields `none/short/unverifiable` stops with fixed copy in `deposit-flow.ts`.
