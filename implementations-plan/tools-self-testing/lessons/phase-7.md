# Phase 7 — Spike: an embedded wallet behind the iframe handler connects to the local tools build

Run as a real spec (`apps/tools/tests/browser/specs/spike.spec.ts`) through the runner, against the
production-mode local build served with its generated CSP. Verdict: **go** — no SDK changes, no
fallback shim needed.

## What the spike found on the way

- **Node's ESM loader vs the harness.** The Playwright runner is the one Node process that loads `@nulo/bridge-core/sandbox`. Two JSON-import shapes broke it: bridge-core's own hub artifact import (fixed with `with { type: "json" }`, which Bun and Vite accept too) and the `@aztec/*` lazy entrypoints (`@aztec/accounts/testing`, reached through `@aztec/wallets/testing`), whose dynamic JSON imports are "incompatible with NodeJS" by their own comment. `tests/browser/node-json-imports.mjs` registers a resolve hook that makes every `.json` module resolve as `type: "json"` — Bun's behaviour, for this runner only (`NODE_OPTIONS=--import`).
- **The wallet must know the SponsoredFPC.** tools names the sponsor as fee payer and never registers it ("Nulo's dispatcher materializes the embedded fee path on the wallet side" — `sponsored-fpc.ts`). A stock embedded wallet fails the drip's `sendTx` with `Cannot sync contract <sponsor>: its instance is not registered nor published`; the test wallet registers the protocol-salt instance at boot, as a real wallet on a sponsored network does.
- **tools reads private gas before its own registration lands.** On connect the console shows `Error handling executeUtility: Cannot sync contract <PrivateFPC>` followed by `[bridge:deposit] private FJ balance read failed (fail-closed → null)`: the account is applied (and the wizard reads) before `finishSetup` registers the PrivateFPC with the wallet. Nulo already holds the FPC so the extension never sees it. Whether the read recovers after `connected` is what cell 1 (credit-paid claim) will show.
- **The idle network builds no block, so a browser claim waits forever.** The local network proposes a block only when a transaction arrives (plan: "blocks only on demand"); the harness nudges one with `forceBlock` wherever it waits on a message. A deposit driven from the UI has no such nudge: the L1 tx landed, the own-gas source resolved (`public`, 5 FJ), and the app then polled for the L1→L2 message that no block would ever carry — the run showed only balance polls for eight minutes. The suite's `test` now carries a worker-scoped auto fixture: the relayer revokes a random public authwit every 3 s for the worker's whole life, the same nudge as the harness. It is the one place the e2e differs from a real network, which builds blocks by the slot.
- **A landing route quote stands the review down.** The wizard invalidates a frozen review whenever a watched input moves, and the route probe (`routeOutcome`) lands asynchronously after the amount step opens; a page object that reaches the review within 0.4 s of the step always saw the generic stand-down. The token+gas card is enabled while the probe is in flight, so "the gas choice is enabled" was no signal. `AmountStep` now exposes `data-route-loading` and `reviewDeposit` waits for it to clear; `confirmReview` keeps its bounded retry for the reads the confirm itself triggers.
- **A stood-down review is not a stuck one.** Diagnosing the above needed to know which hold kept the confirm on "SENDING…": `SendWizard` now logs `[bridge:send] busy {preflighting, submitting, send, exit}` on every transition, the stand-down with its reason, and the preflight read's duration; the test wallet logs every RPC the handler dispatches with its duration (`→ executeUtility #26` / `← executeUtility #26 380ms`). Both are cheap and stay: the page fixture forwards `[bridge*` and `[test-wallet*` lines into the runner's log.
- **Init scripts run before the document has an element** — a `MutationObserver` on `document.documentElement` is a silent no-op; observe `document`.
- **Playwright fixtures**: the actor pool is worker-scoped (= per spec file, since `l1Index` is unique per file and option values select the worker); a test-scoped pool re-created six actors per test.
- Runner ergonomics that paid for themselves within the hour: `NULO_E2E_KEEP=1` (leave the sandbox + both builds) and `NULO_E2E_ATTACH=<state dir>` (`NULO_E2E_REBUILD=1` to rebuild) turn a 4-minute iteration into a 1-minute one.
