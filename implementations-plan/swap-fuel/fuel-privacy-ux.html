What this commits us to

Private-by-default is a strong privacy stance — but it collides with the missing private-FeeJuice path. The default bridge wants gas, and today a private bridge can't have it. So the verdict effectively decides the roadmap:

  • Build private fuel next (PrivateFPC / PrivateMintAndPayFeePaymentMethod) — then the private default carries private gas and the form is whole. My recommendation, since the default is now private.
  • Ship B interim — private default, gas greyed under PRIVATE, a one-line "switch to Public for gas" nudge. Honest, but the headline feature (arrive-with-gas) is off on the default path until private fuel ships.

Either way I can build the real form to this design now (cards, private default, gas-greyed-on-private), and we layer private fuel in when it's ready. Say go and I'll implement + wire it to the live deployment.
