The "keystone" (why I'm confident the cross-chain plumbing is right)

An L1→L2 message only works if both sides compute the exact same content hash — the thing that bit you on Holonym. I pinned the 3 canonical hashes as fixed test vectors and proved them byte-identical across all three toolchains: Solidity (Foundry), Noir, and TypeScript. If any side ever drifts, a test goes red instead of funds stranding on-chain.
