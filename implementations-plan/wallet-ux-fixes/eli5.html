What ships in this PR (safest first — both codex-approved)

Phase 1 — Backup download stops closing the popup

Right now, clicking "Download backup" asks the browser for download permission after making the backup, which pops a prompt that closes the wallet and makes you start over. Fix: ask for that permission at install time instead, so the download just happens — no prompt, no restart.

Proves itself by: both browser builds pass with the permission baked in, a unit test (forcing the "not-granted" branch) confirms the download path never pops a prompt, lint + typecheck green.

Phase 2 — Imported wallets land on the right default network

Import a wallet and it defaults to Testnet, even though the extension's default is Alpha V5 — confusing. The old code hard-coded "Testnet" as the fallback; a recent change moved the real default to Alpha but missed this spot. Fix: the fallback now asks the network service for the actual default, so imported and fresh wallets always agree. (Remembering the exact network you were on across export/import is the split-out PR-B.)

Proves itself by: a test that the fallback returns the build's real primary network (Alpha normally, Testnet in the test environment — proving it reads one source, not a hard-coded name), plus an import smoke test.

Split out (not in this PR)

  • PR-D — the account-switch privacy fix (item 3). This is the one that kept growing. Switching accounts can show one account's transactions, incoming transfers, and pending actions under another — on both the home feed AND the History page — because several data paths aren't scoped or guarded against a mid-switch race. Fixing it right means one shared guard across both pages plus a real design decision (dApp actions don't currently record which account they belong to). Too big and too sensitive to bundle — its own PR, likely its own plan.
  • PR-B — remember the exact active network across backup import. My first mechanism was wrong (proven unimplementable); the corrected approach is a small backup-format change, security-sensitive enough for its own plan.
  • PR-C — the network-list redesign (item 4). The design choice below.

Human context

The extension recently switched its default network to Alpha V5 (mainnet). The test suite deliberately runs on Testnet because CI can't reach the real Alpha network without stalling — which is exactly why the "just use Alpha" shortcut would have broken the tests, and why the fix reads the default from one place that already knows about that test setting.
