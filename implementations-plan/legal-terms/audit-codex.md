**Reject — high confidence: Shape A has a confirmed transaction bypass, incomplete attribution coverage, and insufficient proof against UI lock-out.**

1. **HIGH — Transactions and signing escape the proposed guards.** `AuthRegistryService.revokeAuthwits()` and `setRegistryEnabled()` call `executeSendTransaction()` directly ([service.ts:283](apps/extension/src/wallet/services/auth-registry/service.ts:283), [:337](apps/extension/src/wallet/services/auth-registry/service.ts:337)). Neither planned execution guard intercepts them. Your “two public entry points” fact conflates the RPC interface with public service methods. Separately, fee estimation builds and caches signed requests ([transfer-executor.ts:332](apps/extension/src/wallet/services/execution/transfer-executor.ts:332)); disabling Send leaves its estimation watcher active ([send.vue:409](apps/extension/src/popup/pages/send.vue:409)). Guard direct transaction execution and signing estimators; explicitly define whether declining permits protective revocation.

2. **HIGH — “Not now” can abandon a dApp approval without settling it.** The sheet excludes passkey windows but includes discovery/capability/execute windows. Routing one to `/popup/legal/declined` unmounts its approval component. Its teardown removes the rejection listener without rejecting the interaction ([useDappApprovalWindow.ts:134](apps/extension/src/composables/useDappApprovalWindow.ts:134)). Discovery remains reachable while stale. Define explicit rejection/closure before navigation, or exclude interaction windows and direct users to the ordinary popup. **Confidence: high for the lifecycle conflict.**

3. **HIGH — Export availability is unproved, especially for passkeys.** Passkey full-backup authentication uses an **in-page** ceremony ([full.vue:147](apps/extension/src/popup/pages/settings/security/export/full.vue:147)); excluding `windows/passkey` does not protect it. Specify overlay priority, focus ownership, cancellation, and dismissal before export. Existing barriers use `z-index:10000` ([BarrierOverlay.vue:36](apps/extension/src/components/composite/BarrierOverlay.vue:36)). A grep for guard imports proves no UI reachability property. Test missing/corrupt/stale acceptance with password phrase/account/full export and passkey full export, including cancellation and reopening Review. **Confidence: moderate that unspecified composition causes lock-out; high that current tests cannot exclude it.**

4. **HIGH — A module-owner walk cannot establish “exactly what ships.”** The Buffer shim already contains bundled `base64-js`, `ieee754`, and Buffer implementation code ([shim:3](apps/extension/node_modules/vite-plugin-node-polyfills/shims/buffer/dist/index.js:3), [:243](apps/extension/node_modules/vite-plugin-node-polyfills/shims/buffer/dist/index.js:243)); attributing its owning package loses embedded provenance. SQLite spawns a separate worker ([store.js:98](apps/extension/node_modules/@aztec/kv-store/dest/sqlite-opfs/store.js:98)), and [Vite requires separate build-worker plugins](https://vite.dev/config/worker-options). Aggregate worker graphs and explicit vendored/asset provenance. Inspect emitted chunk membership rather than every loaded module, which can over-include eliminated code. Two package-name canaries establish almost nothing about completeness. **Confidence: high.**

5. **HIGH — Arc C has additional concrete blockers.** Bundled `pako` declares `(MIT AND Zlib)` ([package.json:24](apps/extension/node_modules/pako/package.json:24)); Zlib is excluded. `@aztec/sqlite3mc-wasm` has neither a license field nor a top-level license file ([package.json:1](apps/extension/node_modules/@aztec/sqlite3mc-wasm/package.json:1)). Presto’s relicense therefore cannot make this gate green. Handle SPDX **AND**, investigate SQLite’s vendored provenance, and retain package-specific notices; an SPDX template cannot reconstruct missing copyright attribution. **Confidence: high.**

6. **MEDIUM — Shape B’s single writer is already valuable.** Two tabs can read the same history, append independently, and overwrite one acceptance. Mirroring `createOnboardingFlag()` also publishes optimistic state before persistence ([app.store.ts:126](apps/extension/src/stores/app.store.ts:126)). Await successful storage before enabling actions, serialize history updates, and prevent an initial snapshot overwriting newer events—the existing migration barrier explicitly handles that race ([MigrationBarrier.vue:60](apps/extension/src/components/MigrationBarrier.vue:60)). Prefer B’s serialized SW write path while retaining A’s enforcement and device scope. Per-call reads avoid cache invalidation, but their latency is unmeasured; [Chrome documents asynchronous storage](https://developer.chrome.com/docs/extensions/reference/api/storage), not transactional read-modify-write. **Confidence: high.**

7. **MEDIUM — Version semantics need explicit invariants.** Comparing only major/minor silently accepts a **material patch** unless the manifest forbids one ([plan.md:81](implementations-plan/legal-terms/plan.md:81)). Require monotonic versions and a material baseline for each document. Define unknown/future versions and downgrade behavior without overwriting newer evidence. Keep timestamps informational: clock skew must not revoke consent or reorder history. Privacy-only changes need document-labelled deltas and a Privacy link; U4 currently promises “Read the full Terms.” A capped history is a rolling history, not a complete append-only ledger. **Confidence: high.**

8. **MEDIUM — Discovery is outside the advertised blanket refusal.** Existing sessions auto-approve discovery without dispatch ([background.ts:687](apps/extension/src/wallet/services/wallet-sdk/background.ts:687)). Blocking every dispatcher method consequently preserves transport discovery but blocks `requestCapabilities`/`getAccounts`. That is coherent if documented; “refuses dApp requests” is broader. Also, `enforceMethodAndScope()` is synchronous ([dispatcher.ts:673](packages/wallet-bridge/src/dispatcher.ts:673)): the storage-backed hook must be explicitly awaited before routing. **Confidence: high.**

9. **MEDIUM — The phase gates are incomplete or misplaced.** Root `test:components` does not exist; the extension’s command filters only `src/components`, excluding onboarding components. Root `test` runs extension tests, and CI’s `test:all` does not discover root `scripts/third-party-notices` tests ([package.json:17](package.json:17), [_unit-tests.yml:24](.github/workflows/_unit-tests.yml:24)). Move acceptance fixtures/mocks into P3/P4, when enforcement first breaks existing callers, rather than deferring to P7. **Confidence: high.**

10. **MEDIUM — Fixture seeding can conceal the failures under review.** Relaunches also execute the unconditional seed location ([extension.ts:193](apps/extension/tests/e2e/fixtures/extension.ts:193)); add an option preserving missing/stale records across restart.
