Fuel tab: a "Mint $AZTEC" button

The Fuel tab turns your L1 $AZTEC into Aztec gas (Fee Juice). But it assumed you already had some $AZTEC. This plan adds a one-click Mint 1000 test $AZTEC card to the Fuel tab, so someone starting from zero can mint the test asset and then fuel it — no hunting for a faucet elsewhere. It's a testnet faucet button, mirroring the "Mint test USDC" card the Bridge tab already has.

Why this tier was chosen

Light. Risk rubric scored 0 of 6 HIGH: it copies an existing pattern (low novelty), is a faucet-only testnet button (low blast radius), mints test tokens (nothing irreversible), needs no migration, calls the standard Aztec handler contract, and touches no secrets or auth (low security sensitivity). One codex review is the right amount of ceremony.

Phases

Phase 1: The plumbing (config + mint function)

Pin the handler contract's address, and add a mint() to the existing L1 fee-asset helper: it calls the handler to mint 1000 $AZTEC to your wallet, waits for the Ethereum confirmation, then refreshes your balance. Before minting it double-checks the handler really hands out the right asset (a fail-closed safety check, same as the deposit path already does for the portal).

Proves itself by: a unit test for the mint + the safety check, plus typecheck and lint, all green.

Phase 2: The button (a card on the Fuel tab)

A "Mint $AZTEC" card on the Fuel tab — same look and behavior as the Bridge tab's "Mint USDC" card (connect-wallet gating, a loading state, an error message if the mint reverts). Clean copy (no em dashes, no header repeating the page title — matching the copy pass we just did).

It also fixes a small dead-end codex caught: the fuel amount box defaulted to 12, but the minimum is now 16, so minting then fueling would have errored on a too-small amount. The default becomes 20.

Proves itself by: a component test for the button states + the jsdom fuel smoke test, plus typecheck, lint, and a production build, all green.

Human context

"Fee Juice" is how you pay for transactions on Aztec (its gas). To get it, you bridge an L1 token called $AZTEC across to Aztec. On the test network, that $AZTEC token has an official faucet contract (a "FeeAssetHandler") that mints a fixed 1000 to anyone who asks — that's what this button calls. The address comes from the network itself; we're pinning it in our config (your choice) with a safety check that refuses to mint if the pinned handler doesn't point at the expected asset.
